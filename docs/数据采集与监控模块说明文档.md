# 数据采集与监控模块 (P0) 说明文档

## 1. 模块概述

数据采集与监控模块是一个用于管理工厂设备传感器、采集传感器数据、配置报警规则和处理报警记录的综合解决方案。

### 1.1 功能特性

- **传感器管理**：配置设备上的传感器，包括编码、类型、单位等
- **数据采集**：通过 HTTP 接口接收设备/网关上报的传感器数据
- **实时监控**：查看各设备传感器的最新值
- **历史数据**：查询和导出传感器历史采集数据
- **报警规则**：配置阈值报警规则（大于、小于、超出区间等）
- **报警记录**：查看、确认、关闭报警，完整的报警处理闭环

### 1.2 技术架构

- **后端**：Spring Boot + MyBatis（RuoYi 框架）
- **前端**：Vue.js + Element UI（RuoYi-Vue）
- **数据库**：MySQL 5.7+

## 2. 数据库设计

### 2.1 表结构

#### device_sensor（设备传感器表）

| 字段 | 类型 | 说明 |
|------|------|------|
| sensor_id | bigint | 传感器ID（主键） |
| device_number | int | 设备编号（关联device表） |
| sensor_code | varchar(100) | 传感器编码（设备侧唯一） |
| sensor_name | varchar(200) | 传感器名称 |
| sensor_type | varchar(50) | 传感器类型（temperature/pressure/vibration/current/custom） |
| unit | varchar(50) | 单位（℃、MPa、mm/s、A 等） |
| collect_interval | int | 采集周期（秒） |
| status | char(1) | 状态（0启用 1停用） |
| remark | varchar(500) | 备注 |

**唯一约束**：`device_number + sensor_code`

#### sensor_data（传感器数据表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键ID |
| sensor_id | bigint | 传感器ID |
| device_number | int | 设备编号（冗余） |
| value | decimal(20,6) | 采集值 |
| data_time | datetime | 采集时间 |
| create_time | datetime | 入库时间 |

**索引**：`(sensor_id, data_time)`、`(device_number, data_time)`

#### alarm_rule（报警规则表）

| 字段 | 类型 | 说明 |
|------|------|------|
| rule_id | bigint | 规则ID（主键） |
| rule_name | varchar(200) | 规则名称 |
| sensor_id | bigint | 传感器ID |
| compare_type | varchar(20) | 比较类型（gt/ge/lt/le/between） |
| threshold_min | decimal(20,6) | 阈值下限 |
| threshold_max | decimal(20,6) | 阈值上限 |
| severity | varchar(20) | 严重程度（low/medium/high） |
| enabled | char(1) | 是否启用（0停用 1启用） |
| description | varchar(500) | 规则描述 |

#### alarm_record（报警记录表）

| 字段 | 类型 | 说明 |
|------|------|------|
| alarm_id | bigint | 报警ID（主键） |
| rule_id | bigint | 规则ID |
| device_number | int | 设备编号 |
| sensor_id | bigint | 传感器ID |
| alarm_time | datetime | 报警触发时间 |
| alarm_value | decimal(20,6) | 触发时的值 |
| severity | varchar(20) | 严重程度 |
| status | varchar(20) | 状态（new/acknowledged/resolved） |
| handled_by | varchar(64) | 处理人 |
| handled_time | datetime | 处理时间 |
| remark | varchar(500) | 备注 |

## 3. API 接口文档

### 3.1 传感器管理

#### 查询传感器列表
```
GET /monitor/sensor/list
```
**权限**：`monitor:sensor:list`

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| deviceNumber | Long | 否 | 设备编号 |
| sensorCode | String | 否 | 传感器编码（模糊匹配） |
| sensorType | String | 否 | 传感器类型 |
| status | String | 否 | 状态 |
| pageNum | Integer | 是 | 页码 |
| pageSize | Integer | 是 | 每页条数 |

#### 新增传感器
```
POST /monitor/sensor
```
**权限**：`monitor:sensor:add`

**请求体**：
```json
{
  "deviceNumber": 15,
  "sensorCode": "TEMP_001",
  "sensorName": "主轴温度传感器",
  "sensorType": "temperature",
  "unit": "℃",
  "collectInterval": 60,
  "status": "0",
  "remark": "监测主轴运行温度"
}
```

#### 修改传感器
```
PUT /monitor/sensor
```
**权限**：`monitor:sensor:edit`

#### 删除传感器
```
DELETE /monitor/sensor/{sensorIds}
```
**权限**：`monitor:sensor:remove`

---

### 3.2 数据采集与查询

#### 采集上报接口 ⭐
```
POST /monitor/data/collect
```
**说明**：设备/网关调用此接口上报传感器数据

**请求体**：
```json
{
  "deviceNumber": 15,
  "sensorCode": "TEMP_001",
  "value": 68.5,
  "dataTime": "2026-01-15 00:10:00"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| deviceNumber | Long | 是 | 设备编号 |
| sensorCode | String | 是 | 传感器编码 |
| value | BigDecimal | 是 | 采集值 |
| dataTime | Date | 否 | 采集时间（不传则使用服务器时间） |

**返回示例**：
```json
{
  "code": 200,
  "msg": "数据上报成功",
  "data": {
    "success": true,
    "sensorId": 1,
    "dataId": 100,
    "alarmCount": 1
  }
}
```

#### 查询最新数据
```
GET /monitor/data/latest?deviceNumber=15
```
**权限**：`monitor:data:view`

**说明**：获取指定设备各传感器的最新采集值

#### 查询历史数据
```
GET /monitor/data/list
```
**权限**：`monitor:data:view`

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| deviceNumber | Long | 否 | 设备编号 |
| sensorId | Long | 否 | 传感器ID |
| beginDataTime | String | 否 | 开始时间 |
| endDataTime | String | 否 | 结束时间 |

---

### 3.3 报警规则管理

#### 查询规则列表
```
GET /monitor/rule/list
```
**权限**：`monitor:rule:list`

#### 新增规则
```
POST /monitor/rule
```
**权限**：`monitor:rule:add`

**请求体**：
```json
{
  "ruleName": "主轴温度过高报警",
  "sensorId": 1,
  "compareType": "gt",
  "thresholdMax": 85.0,
  "severity": "high",
  "enabled": "1",
  "description": "主轴温度超过85℃触发高级别报警"
}
```

**比较类型说明**：
| compareType | 说明 | 触发条件 |
|-------------|------|----------|
| gt | 大于 | value > threshold_max |
| ge | 大于等于 | value >= threshold_max |
| lt | 小于 | value < threshold_min |
| le | 小于等于 | value <= threshold_min |
| between | 超出区间 | value < threshold_min OR value > threshold_max |

---

### 3.4 报警记录

#### 查询报警列表
```
GET /monitor/alarm/list
```
**权限**：`monitor:alarm:list`

**参数**：
| 参数 | 类型 | 说明 |
|------|------|------|
| deviceNumber | Long | 设备编号 |
| severity | String | 严重程度（low/medium/high） |
| status | String | 状态（new/acknowledged/resolved） |
| beginAlarmTime | String | 开始时间 |
| endAlarmTime | String | 结束时间 |

#### 确认报警
```
POST /monitor/alarm/ack/{alarmId}
```
**权限**：`monitor:alarm:handle`

**说明**：将报警状态从 `new` 改为 `acknowledged`

#### 关闭报警
```
POST /monitor/alarm/resolve/{alarmId}
```
**权限**：`monitor:alarm:handle`

**请求体**（可选）：
```json
{
  "remark": "已处理，设备恢复正常"
}
```

## 5. 核心业务流程

### 5.1 数据采集流程

```
设备/网关 → POST /monitor/data/collect → 
  1. 根据 device_number + sensor_code 查找传感器
  2. 写入 sensor_data 表
  3. 查询该传感器的启用规则
  4. 逐条做阈值判断
  5. 若触发报警：
     - 检查是否有活动告警（去重）
     - 有则更新，无则新增 alarm_record
  6. 返回结果
```

### 5.2 报警去重策略

同一 `rule_id + sensor_id` 组合，在 `status != resolved` 时：
- 不新增重复报警记录
- 更新现有记录的 `alarm_time` 和 `alarm_value`

### 5.3 报警状态流转

```
new (待处理) → acknowledged (已确认) → resolved (已关闭)
       ↘                              ↗
         ————————————————————————————
```
